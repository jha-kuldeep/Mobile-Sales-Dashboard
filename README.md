# 📊 Mobile Sales Analytics Dashboard (Power BI)

## 🔍 Overview

This project presents an interactive **Power BI dashboard** built to analyze mobile sales data and generate actionable business insights.

It demonstrates the complete **data analytics lifecycle** — from data cleaning and transformation to visualization and storytelling — helping stakeholders make data-driven decisions efficiently.

---

## 💼 Business Problem

Organizations often lack a unified view of:

* Sales performance across regions
* Product and brand contribution
* Customer purchasing behavior
* Payment trends

This dashboard provides a **centralized solution** to monitor and analyze these key metrics in real time.

---

## 🎯 Key Insights

* 📈 **₹769M+ Total Sales** across all regions
* 🌆 Metro cities drive the highest revenue contribution
* 📅 Monthly trends reveal **seasonal demand patterns**
* 💳 **UPI & Card payments dominate** transaction methods
* 📱 Premium models generate **higher revenue per unit**
* ⭐ Customer ratings indicate **strong satisfaction levels**

## 🧠 Skills Demonstrated

* Data Modeling & Relationships
* DAX for KPIs and calculated measures
* Interactive dashboard design

---

## 📊 Dashboard Features

* **KPI Cards** – Total Sales, Quantity, Transactions, Avg Price
* **Map Visualization** – City-wise sales distribution
* **Trend Analysis** – Monthly & daily performance
* **Customer Insights** – Ratings breakdown
* **Payment Analysis** – Mode of transactions
* **Product Insights** – Brand & model performance
* **Dynamic Filters** – Month, Brand, Model, Payment Method
